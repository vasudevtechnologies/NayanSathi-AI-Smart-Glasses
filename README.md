# NayanSathi-AI-Smart-Glasses
🕶️ NayanSathi — AI Smart Glasses for the Visually Impaired NayanSathi is an AI-powered wearable assistive system designed to help visually impaired individuals navigate and understand their surroundings in real time. Built using Raspberry Pi 4, ESP32-CAM, YOLOv11, and Edge AI technologies, the smart glasses detect nearby objects

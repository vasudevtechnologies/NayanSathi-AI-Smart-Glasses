Core Capabilities

Everything You Need to See the World

Cutting-edge AI features packed into a lightweight wearable that empowers independence.

👁️

Real-Time Object Detection

YOLOv11 ONNX model detects 80+ objects at 8–15 FPS on Raspberry Pi 4 CPU. Priority-based voice announcements for critical objects like people, cars, and traffic lights.

YOLOv11 · 80 Classes
🔊

Voice Assistance (TTS)

Piper TTS generates natural Indian English speech directly on the Pi. Spatial audio cues tell the user if objects are left, right, near, or far — no cloud needed.

Piper TTS · Offline
🤖

Raspberry Pi Edge AI

All AI processing runs locally on Raspberry Pi 4 (4GB). Zero cloud dependency, zero latency spikes, complete privacy. ONNX Runtime optimized for ARM CPU.

Edge AI · 100% Private
📷

ESP32-CAM Streaming

ESP32-CAM with OV2640 sensor streams MJPEG video over WiFi to Raspberry Pi. UART communication for seamless frame-by-frame AI inference pipeline.

MJPEG · WiFi Stream
☀️

Solar Assisted Charging

5V/2W solar panel with TP4056 charge controller extends battery life during outdoor use. 5000mAh Li-Po battery provides 6–8 hours of continuous operation.

Solar + USB-C Charging
🎧

Bluetooth Audio

Bluetooth 5.0 connects wirelessly to earbuds for discrete audio output. Hands-free, cable-free audio delivery without compromising user mobility or safety.

BT 5.0 · Wireless
📊

Live Web Dashboard

Real-time monitoring dashboard accessible from any browser. View live camera feed, detection logs, system stats, SSH terminal, and voice command control panel.

WebSocket · Node.js
🛡️

Browser AI Fallback

TensorFlow.js COCO-SSD model runs directly in browser as a fallback detection mode. Enables web-based demos without any hardware — perfect for evaluation.

TF.js · Browser-Based
🌐

Public Tunnel Access

Cloudflare, ngrok, and LocalTunnel support for secure remote access to the dashboard from anywhere in the world. Monitor and control the glasses remotely.

Cloudflare · ngrok
